# ICIT UDP — Malla Interactiva

Malla curricular interactiva de **Ingeniería Civil en Informática y Telecomunicaciones de la Universidad Diego Portales**, representada como un árbol de logros inspirado en el sistema de avances de **Minecraft**.

Cada asignatura se presenta como un logro desbloqueable, conectado con sus respectivos prerrequisitos y organizado según su área académica. El objetivo es transformar la malla curricular tradicional en una experiencia visual e interactiva que permita explorar la progresión de la carrera y el camino hacia la titulación.

## Tecnologías

* Next.js
* React
* TypeScript
* Tailwind CSS
* Lucide React

## Concepto

> Cada asignatura es un logro. Cada prerrequisito, un camino. Cada semestre, una nueva etapa.
